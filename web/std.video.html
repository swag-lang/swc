Video

Video reads and writes silent video streams as timed sequences of Pixel.Image frames.

The first codec is YUV4MPEG2 (.y4m) with progressive 8-bit 4:4:4 YCbCr frames. File-backed clips index their frame payloads without decoding them, then materialize one frame at a time through Video.Clip.decodeFrame. This keeps playback memory bounded independently of the file duration.

#import("video") using Video let rate = try FrameRate.create(24, 1) var clip = try Clip.create(320, 180, rate) let frame = Pixel.Image.create(320, 180, .RGB8) try clip.addFrame(frame) try clip.save("preview.y4m") let loaded = try Clip.load("preview.y4m") let first = try loaded.decodeFrame(0)

YUV4MPEG2 carries no audio. Alpha is discarded during encoding, and decoded frames use Pixel.PixelFormat.RGB8. Malformed streams, unsupported chroma or interlacing, inconsistent frames, and file access errors use Swag's normal fail mechanism.

Reading and writing video

Video.Clip represents a silent timed sequence of equal-sized Pixel.Image values. The initial YUV4MPEG2 codec deliberately favors a small, portable implementation over compression: it stores progressive 8-bit Y, Cb, and Cr planes at full 4:4:4 resolution.

Use Video.Clip.load for playback. It reads the header and indexes frame payloads, but does not decode their pixels. Video.Clip.decodeFrame then reopens the source and reads only the selected frame. Keep the source file available for as long as frames may still be requested.

Create an empty clip with fixed geometry and a Video.FrameRate, add matching images, then call Video.Clip.save. The writer accepts every 8-bit Pixel RGB or BGR format and drops alpha. It converts through limited-range BT.601 YCbCr; the decoder also honors the YUV4MPEG2 full-range tag. A decoded round trip can differ by a few channel values.

YUV4MPEG2 has no audio stream. Audio tracks and synchronization will belong to future container codecs and will compose with the standard Audio module rather than adding a second sound implementation here.

struct Video.Clip #src

Owns or indexes a silent sequence of equal-sized image frames.

A clip created with Video.Clip.create owns every image added to it. A clip decoded from memory owns a copy of the encoded bytes. A file-backed clip keeps only the source path and frame offsets; keep that file available while calling Video.Clip.decodeFrame.

struct Video.FrameRate #src

Describes an exact number of video frames per second.

The rate is numerator / denominator. Both parts are positive and remain unchanged, so broadcast rates such as 30000 / 1001 do not lose precision.

func Clip.addFrame #src

Adds an owned copy of one frame to a created clip.

The image dimensions must match the clip. All four 8-bit Pixel RGB and BGR formats are accepted; alpha is retained in memory and discarded only when encoding YUV4MPEG2. Frames cannot be appended to a loaded or decoded clip.

Decodes one frame to an owned RGB8 image.
