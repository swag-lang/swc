# Design campaigns

Each folder is one design campaign: its specification, its pictures, and the backlog entries
that remain before the code matches them. A folder disappears when its entries are done; a
charter that outlives its migration stays as the contract it describes.

| Folder | Campaign |
| --- | --- |
| [silence/](silence/README.md) | Silence, the GUI charter: themes, controls, dialogs and the three standard applications. Its migration entries are in [design.silence.md](silence/design.silence.md). |
| [multiview/](multiview/README.md) | Swag Scope with several files: scenes in tabs, split views, comparison and synchronized grids. Its entries are in [design.multiview.md](multiview/design.multiview.md). |

A campaign follows Silence. Where a campaign's picture and the Silence charter disagree, the
charter wins until the campaign changes it in the charter itself.
