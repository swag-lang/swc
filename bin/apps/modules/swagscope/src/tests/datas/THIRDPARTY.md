# Swag Scope fixture sources and licences

## Repository-generated fixtures

`viewer.project.zip` is a deterministic ZIP bundle authored for Swag Scope's archive reader. Its
fictional field-survey project has seven UTF-8 files: a root README and fixture licence, nested
site configuration, observation data, handling notes, and source/catalog files. The archive uses
Deflate compression at level 6, fixed timestamps (`2020-01-02 03:04:06`), and Unix regular-file
permissions (`0644`) so it is reproducible. The UTF-8 source text is authored in this document's
listed file order and written with Python's `zipfile.ZipFile`/`ZipInfo`. All content is generated
for this repository, including the embedded MIT License; the fixture is covered by this
repository's licence.

`viewer.ensemble.mid` is a generated Standard MIDI File format 1 score with four tracks: a
conductor carrying tempo, meter and key metadata, plus piano, bass and percussion. Its notes and
track labels are original test data; no musical composition is copied. The file is emitted from
absolute-tick events, sorted per track and encoded with MIDI variable-length deltas.

MIDI fixtures listed below. Its compressed payloads are part of the generator source; regeneration uses
only Python's standard library, with no network, external corpus, fonts, random input or media. The
field notes and timed captions describe fictional North Basin observations. The Markdown, HTML and
MIDI examples retain their format and visual-regression cases while using repository-authored
content. All are covered by this repository's licence. Aliases are copied byte-for-byte from their
canonical source.

## Arabic font fixtures

`viewer.arabic.ttf` and `viewer.arabic.ttc` are regenerated by
`generator/make-arabic-font-fixtures.py` with FontTools 4.61.1. The input faces are the
Noto Sans Arabic Regular and Bold TTFs from the Noto project (`NotoSansArabic-Regular.ttf` and
`NotoSansArabic-Bold.ttf`), distributed under SIL Open Font License 1.1. The script subsets the
complete basic Arabic block plus characters used by `comprehensive.txt`, keeps layout features
for Arabic shaping, renames the family to `Swag Scope Arabic Fixture`, and fixes font timestamps
for reproducible output. The TTC contains the Regular face at index 0 and Bold at index 1.

- Source: [Noto Sans Arabic](https://github.com/notofonts/arabic), Noto fonts source; packaged
  copies are from Debian `fonts-noto-core`.
- Source input hashes: Regular `504d7407d86875acf7d04dfaa0fd7524d0b8797723bc4aa18022f29db25b0b6e`,
  Bold `ded6fc7359ca36d15d7aab9ef0c066e21ce48b26a069994d6602fa2cb9a1b952`.
- Generation: `python3 generator/make-arabic-font-fixtures.py --regular NotoSansArabic-Regular.ttf --bold NotoSansArabic-Bold.ttf --output-dir .`
  with FontTools 4.61.1. The full OFL text is in `font-fixture-arabic-OFL.txt`.
