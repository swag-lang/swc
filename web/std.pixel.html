    struct Pixel.Image[src]

    Owns a two-dimensional, tightly packed pixel buffer.

    Pixels are stored row by row without padding in the format given by Pixel.PixelFormat. Copying an image copies its owned byte array; temporary working storage is never shared.

    Example

    var image = Image.create(64, 64, .RGBA8) image.fill(Color.fromRgb(18, 24, 32))

    struct Image.SmartCropSearchOpts[src]

    Smart crop search parameters

    struct SmartCropSearchOpts

    Fields

    blurRadiuss32

    Blur radius (in pixels) applied to the saliency map for smoothing. Range: 0–5 (typical 2–4). Higher = smoother gradients, less fine detail.

    centerWeightf32

    Weight for proximity to the image center (center bias). Range: 0.0–0.3 (typical 0.05–0.15). 0.0 removes center preference.

    edgePenaltyf32

    Penalty for crops that cut through strong edges (uses edge-distance map). Range: 0.0–0.5 (typical 0.10–0.25). 0.0 disables the edge term.

    faceWeightf32

    Reserved for future face detection bonus when faces are inside the crop. Range: 0.0–1.0 (currently unused).

    maxSearchStepss32

    Number of scale steps in multi-scale search. Range: 5–20 (typical 8–12). More = more thorough but slower.

    maxSizes32

    Maximum working image size (pixels) for the longest side when computing crops/scores. 0 (or <=0) disables downscaling. The original image is always used for the final crop.

    minCoveragef32

    Minimum fraction of the original image area the crop must keep. Range: 0.0–1.0. Lower allows tighter crops; higher preserves more context. Special: >= 0.95 triggers fast single-scale mode (no multi-scale search).

    shrinkPriorf32

    Prior favoring larger crops (adds an area-proportional bonus). Range: 0.0–0.3 (typical 0.05–0.15). 0.0 means no size preference.

    strideFracf32

    Search stride as a fraction of the crop size (per axis). Range: 0.01–0.20 (typical 0.06–0.12). Lower = slower, higher quality.

    thirdsWeightf32

    Weight for the rule-of-thirds compositional bonus. Range: 0.0–0.5 (typical 0.15–0.25). 0.0 disables thirds influence.

    struct Pixel.MathExpression[src]

    Parsed, reusable mathematical expression. The accepted input is a practical LaTeX math subset; no surrounding $ delimiters are needed. It includes:

    • grouped rows, Unicode literals, sub/superscripts and TeX atom spacing;
    • fractions, binomials, indexed roots, scalable delimiters and common accents;
    • Greek letters, relations, arrows, named functions and large operators/limits;
    • roman/italic/bold/text runs and explicit TeX spacing;
    • matrix, pmatrix, bmatrix, Bmatrix, vmatrix, Vmatrix, cases and aligned.
