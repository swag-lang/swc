Screen

Screen acquires live desktop pixels independently of GUI event handling. A Screen.Source captures one area in physical desktop pixels and writes bottom-up BGRA8 into a reusable Pixel.Image. The source owns its native handles; callers own the returned image.

#import("screen") using Screen var source = try Source.open(SourceOptions{0, 0, 1920, 1080}) var frame: Pixel.Image discard try source.grabInto(&frame)

A source can report a temporary absence of a newer desktop frame. Its last frame remains available for a constant-rate recording. Native source loss is reported through fail and the caller may reopen it after a display change.

func Source.grabInto #src

Writes a bottom-up BGRA8 image, returning true when desktop pixels or the composed cursor changed.

False means no new image is available yet, either because the desktop and cursor did not change or because a video readback is still pending. It is not a source failure. By default the previous picture is copied to target. Set copyUnchanged to false when the caller will reuse its previous encoded picture instead. A reusable target stays untouched on a false return; a new or resized target receives a complete current frame. With updateChangedOnly and copyUnchanged false, successive grabs into the same unmodified target may update only changed regions after the first complete frame. Replacing or resizing the target causes a complete copy. Windows cursor composition rebuilds the selected area each poll to account for pointer-only changes. The target remains owned by the caller.

mtd grabInto(target: *Image, copyUnchanged: bool = true, updateChangedOnly: bool = false)->bool fail
func Source.lastFrameCaptureMicroseconds #src

Returns the monotonic capture-completion time of the latest fresh frame, or zero before one is acquired.

The value uses the same microsecond clock as Core.Time.monotonicMicroseconds. It records when grabInto received a fresh frame, not the display's presentation time, and remains unchanged when a grab returns false. With cursor composition enabled, cursor-only image changes also update it. A successful reopen resets it to zero; failed attempts preserve it.

func Source.openDesktop #src

Opens a source for the current virtual desktop bounds.

The rectangle includes gaps between monitors. It can fail when no desktop bounds are available. includeCursor requests pointer composition where supported and defaults to false.

func Source.openMonitor #src

Opens a source for one currently enumerated physical monitor.

monitorIndex uses the current order from Core.Env.getMonitors and is not a persistent display identifier. The source captures that monitor's full physical bounds and can fail if the display is unavailable. includeCursor requests pointer composition where supported and defaults to false.

func openMonitor(monitorIndex: u64, includeCursor: bool = false)->Source fail

Opens a source for a monitor value returned by Core.Env.getMonitors.

The value is a snapshot of physical bounds, not a persistent display identifier. The source can fail if those bounds are no longer available. includeCursor requests pointer composition where supported and defaults to false.
