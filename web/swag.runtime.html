struct Swag.AllocatorRequest #src

Represents the request for a given allocator. The operation itself is carried by the IAllocator method being called; the request only transports its operands and the tracking metadata.

For IAllocator.alloc:

  • size must be the size in bytes to allocate
  • alignment must be the alignment constraint in bytes (or 0)
  • address will be the returned allocated memory address

For IAllocator.free:

  • size must be the original allocated size in bytes of address
  • address must be the memory address to release

For IAllocator.realloc:

  • size must be the new size in bytes
  • oldSize must be the original allocated size in bytes of address
  • address must be the memory address to reallocate, and receives the new one

attr Swag.BorrowSummary #src

Computed borrow summary of a function, consumed by the static borrow analysis. Bit i of returns means the return value may borrow parameter #i; bit i of stores means parameter #i may be stored in storage that outlives the call; bit i*8+j of into means parameter #j may be stored into storage reachable from parameter #i (packed 8x8); bit i of frees means the call invalidates what parameter #i points to (it reaches IAllocator.free or IAllocator.realloc); bit i of reallocates means the call may move or release the heap payload parameter #i OWNS, which is what invalidates the views taken into it; bit i of returnsPayload means the returned value is a view INTO that payload rather than merely a value that can reach parameter #i, which is what tells a container accessor apart from a factory handing back an object that keeps a back-reference. Emitted automatically in generated module APIs so summaries cross module boundaries; can also be written manually on a Foreign function.
