SWAG

A systems language that runs at compile time.

Get Started
View the Source

Swag compiles Windows x86-64 programs with its own native backend and executes the same language through a JIT during compilation, testing, and script runs. Runtime code and compile-time code share the same types, functions, reflection, error model, and metaprogramming tools.

What the compiler does

Native output

Build executables, shared libraries, and static libraries with a direct x86-64 backend. Release builds can emit Windows debug information alongside the artifact.

Compile-time execution

Evaluate ordinary functions with #run, inspect types, and generate declarations with #ast. Compile-time work uses the language rather than a separate template system.

Executable documentation

The language reference is a tested Swag module. Its examples are parsed, type-checked, and run by the compiler that publishes the site.

func buildMask(bitCount: u32)->u32 { return (1'u32 << bitCount) - 1 } const LowByteMask = #run buildMask(8) #assert(LowByteMask == 0xFF)
Warning

Swag is a pre-1.0 project under active development. The current toolchain targets Windows on x86-64, and source compatibility can change between revisions.
