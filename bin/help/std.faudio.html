FAudio

Raw FAudio C ABI declarations, based on FAudio 25.05.

See https://github.com/FNA-XNA/FAudio/blob/master/include/FAudio.h for the native contract. Function pointers borrow the library that supplied them. This module does not load FAudio or open an audio device; callers load libFAudio.so.0 before resolving its entry points.
