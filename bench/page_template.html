Progress against the reference

The compiler under test is measured next to a frozen Swag compiler, reference {{reference}}, in every campaign: the two are sampled back to back in every round, so they share the machine's state minute by minute. A change is the median of those paired ratios, per task, then the geometric mean over the tasks. No correction is applied between campaigns and none is needed: each point is a ratio measured inside one campaign. Since every campaign is measured against the same reference, the move of a ratio between two campaigns is what the work on the compiler changed in between: ↑ better, ↓ worse, full when measurable, faded within the noise. Hover a series for its per-task values. The shaded band is the 95 % interval of the first curve.

Median time of a complete build from source to a runnable artifact, including each recipe's imports, optimization and linking or bytecode generation. Campaign and method

{{quality}}
  • EstimatorThe median of each series, with a distribution-free 95 % interval from order statistics. Ratios add their uncertainties in log space; a panel uses the geometric mean, as SPEC does.
  • SamplingRounds in a random order recorded with its seed. Each series samples until its interval is narrow enough, its time budget is spent, or its maximum count is reached, after a pilot that prices it.
  • InterferenceEvery sample measures the CPU the rest of the machine used while it ran. A sample that exceeds its family's running median by more than 2.5 cores is set aside and taken again once the machine is quiet.
  • StateSwag is measured from a private copy of the compiler, runtime and library, with private caches. Every toolchain gets one untimed warm-up build, then each sample restores the same warm caches and a clean project.
  • MachineMains power required; the power mode and the toolchain versions are recorded with the campaign. Execution is pinned to one logical processor per performance core; builds use the whole machine.
  • ValidityEvery port prints the same checksum; a campaign with a failed build, run or checksum is not recorded. Raw campaigns, every sample included, live in bench/results; bench/README.md states the protocol.
