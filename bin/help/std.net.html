Module net

Net provides blocking IPv4 TCP connections, bounded HTTP GET requests and URL helpers.

Connect over TCP

#import("net") using Net #main { var connection = try TcpStream.connect({address: [127, 0, 0, 1], port: 8080}) let request = cast(const [..] u8, "hello") var offset = 0'u64 while offset < request.count { let sent = try connection.write(request[offset to]) if sent == 0 do break offset += sent } }

Streams own their connections and close them on drop. Operations can fail and may transfer fewer bytes than requested. Networking is available on Windows in this implementation.

Request an HTTPS resource

#import("net") using Core, Net #main { let target = try Url.parseHttp("https://example.com/?q=swag") let response = try Http.get(target.host, target.port, target.path, target.secure) if response.status == 200 do Console.println(cast(string, response.body.toSlice())) }

HTTPS uses the Windows trust store. Requests have bounded response bodies and return redirects without following them, so the caller can decide which destinations are acceptable.

func Http.get #src

Issues a bounded HTTP or HTTPS GET to host, port and an absolute request path.

path must already be percent-encoded. HTTPS verifies the peer using the Windows trust store. Redirects are returned to the caller instead of being followed. Each phase has the configured timeout setting; WinHTTP may enforce it with coarse timing and can exceed the requested value. The operation is synchronous and cannot be cancelled while a native call is blocked. The result owns its body and includes non-success status codes. Invalid input, transport errors, and a body exceeding maxBodyBytes fail without returning a partial result.

#import("net") using Core, Net #main { let target = try Url.parseHttp("https://example.com/") let response = try Http.get(target.host, target.port, target.path, target.secure) Console.println(response.status) }

+ remains +. A truncated escape or a non-hexadecimal digit fails; unescaped bytes are copied without interpreting or validating UTF-8.

func Url.encodeComponent #src

Percent-encodes bytes for one URL component using the RFC 3986 unreserved alphabet.

UTF-8 text is encoded byte by byte. Spaces become %20, not +; separators such as &, =, / and % are encoded so the result can be inserted as one query value or path segment.

func encodeComponent(bytes: const [..] u8)->String
func Url.parseHttp #src

Parses an absolute HTTP or HTTPS URL into owned request parts.

This deliberately accepts only ASCII host names and IPv4 literals as hosts. User information, IPv6 literals, relative references and non-ASCII URL text are rejected. The path and query stay percent-encoded, an absent path becomes /, and a fragment is omitted. Invalid escapes, malformed ports, spaces and control characters fail.
