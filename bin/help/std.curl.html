Module curl

Raw libcurl C ABI declarations for Linux x86-64 consumers.

Names and contracts follow the libcurl API reference. Function pointers borrow a loaded libcurl.so.4; this module neither loads the library nor initializes it. Native allocations retain libcurl's matching cleanup obligations. Net owns HTTP request policy, bounded response storage, and error translation.
