Scene3d

Scene3d loads bounded triangle scenes from common local model formats. Use Scene3d.Scene.decodableFormats to build a file filter and Scene3d.Scene.canLoad to check an extension or Scene3d.canDecode to probe a complete buffer. Binary STL has no distinct signature, so a header-only probe cannot identify it without the .stl extension.

Scene3d.Scene owns its nodes, meshes, materials, vertices and triangles. The initial codecs read OBJ geometry and ASCII or binary STL; they do not execute scripts, follow external paths, or require a renderer. Coordinates retain the units and handedness declared by the source file.

#import("scene3d") using Scene3d let scene = try load("model.obj") let mesh = &scene.meshes[0] Console.print("% triangles", mesh.triangles.count)

File, syntax, unsupported-format, and resource-limit errors use Swag's fail mechanism. Supply Scene3d.Limits when a caller needs tighter bounds.

Reading model files

Use Scene.decodableFormats to build a file filter and Scene.canLoad to check whether an extension is listed. Use load to open a local model or decode when the caller already owns its bytes. Both select OBJ or STL from a known extension and recognizable content. Pass a Limits value to lower the default byte, vertex, triangle, node, or material ceilings for untrusted files.

The first OBJ codec keeps position, normal, texture-coordinate, and usemtl assignments. It does not open mtllib files or resolve texture paths. STL ASCII and binary facets become triangle meshes; the binary codec requires the declared facet records to fill the file exactly. Both formats produce an identity root node and opaque-white material records where the file does not provide material appearance.

#import("scene3d") using Scene3d var limits: Limits limits.maxInputBytes = 8 * 1024 * 1024 let scene = try load("model.stl", limits) for mesh in scene.meshes do Console.print("% triangles", mesh.triangles.count)

The returned scene owns its arrays. The decoder does not retain the input byte slice.

func Scene3d.canDecode #src

Reports whether a filename hint or recognizable full-buffer content can select a built-in decoder.

Text probes require structural records instead of isolated words, which avoids claiming unrelated text files as OBJ or STL documents. A truncated file header cannot identify binary STL.

func canDecode(fileName: string, bytes: const [..] u8)->bool
func Scene3d.decode #src

Decodes OBJ or STL bytes using their extension and recognizable file content.

fileName supplies a format hint and scene name only; all returned geometry is copied into the result. Binary STL is identified by its declared facet count and exact record length, including when the 80-byte header starts with the word solid.

func decode(fileName: string, bytes: const [..] u8, limits: Limits = {})->Scene fail
func Scene3d.load #src

Loads OBJ or STL data from a file, selecting a decoder by extension and content.

The opened stream is size-checked before reserving owned memory, so a path replacement between checking and reading cannot bypass limits.maxInputBytes. .obj and .stl extensions select their codecs; a recognized file signature also permits an extensionless or otherwise unrecognized name. Referenced OBJ material libraries and textures are not opened.
