# Poly1305 whole-block processing

The new path reads full input blocks in place and keeps the multiplication and carry state
across each batch. Native Release Core passed 17 ChaCha20, Poly1305, and XChaCha20-Poly1305
tests. The added OpenSSL-generated vectors cover every tail after four full blocks, and every
split point through the first block on an unaligned message.

The [native comparison](../../../workloads/crypto/README.md) ran 11 interleaved trials on CPU 4
of an AMD EPYC 9V74. Every digest and ciphertext/tag agreed byte for byte with OpenSSL 3.5.7
and with the previous Swag code at `d9bfeae85f`. Rates are decimal GB/s.
