    struct Pixel.MathExpression[src]

    Parsed, reusable mathematical expression. The accepted input is a practical LaTeX math subset; no surrounding $ delimiters are needed. It includes:

    • grouped rows, Unicode literals, sub/superscripts and TeX atom spacing;
    • fractions, binomials, indexed roots, scalable delimiters and common accents;
    • Greek letters, relations, arrows, named functions and large operators/limits;
    • roman/italic/bold/text runs and explicit TeX spacing;
    • matrix, pmatrix, bmatrix, Bmatrix, vmatrix, Vmatrix, cases and aligned.

    struct Pixel.TextEffect[src]

    TextMeshPro-style text effects for MSDF fonts. They are derived from the glyph distance field, so a single draw produces outline, glow and bevel; the soft drop shadow is rendered as an offset second pass. Effects only apply when the resolved draw font is MSDF (an explicit .Msdf font, or an .Auto font drawn at >= 20px); for a bitmap font they are ignored. Distances are in distance-field units, where 0.5 spans roughly the atlas spread, so widths scale with the text size.
