Compilation

Complete cold build, from source to a runnable artifact, geometric mean across tasks. Each recipe includes its required libraries and headers. Java produces bytecode for HotSpot. The headline speedup is the geometric mean of fastest non-Swag build time / Swag release build time for each task: 2× means Swag builds twice as fast on average; below 1× means slower. All non-Swag build configurations, including bytecode generation, can be the reference. Each task has equal weight; hello is excluded.
