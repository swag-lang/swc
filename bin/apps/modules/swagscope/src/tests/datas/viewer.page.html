Ownership, without ceremony

Ownership

A value has one owner. When the owner goes, the value goes with it: no collector runs behind it, no counter is kept beside it.

Moving

Moving a value hands it over: #move buffer leaves the source empty and the destination responsible.

var a = Array'u8{}
var b = #move a
// a is empty, b owns the bytes
